Три подхода к реализации

Все дают «Slash Drama» — разница в богатстве эффектов и сложности кода

1 — CSS+ / Lean

SVG-дуга на CSS keyframes, 3 дополнительных CSS-искры, тряска через classList. Нет нового риска — всё в рамках текущего стека.

+

  • Минимум JS
  • Никакого рефактора

−

  • Искры предсказуемые
  • Нет flash
canvas ✦

2 — Canvas Hybrid ⭐ Рекомендую

CSS для движения меча, <canvas> поверх — для физичных частиц (gravity, scatter). SVG-дуга на CSS. JS-тряска + impact flash.

+

  • Органичные искры
  • Impact flash
  • Меч — без изменений

−

  • ~60 строк нового JS
canvas ✦✦

3 — Full Canvas

Детальный SVG + CSS blur на меч во время удара (motion blur) + afterimage-дубли + canvas-частицы + glint + flash. Максимум.

+

  • Самое зрелищное
  • Motion blur
  • Afterimage-тени

−

  • ~150 строк нового JS
  • Сложнее под dark theme
