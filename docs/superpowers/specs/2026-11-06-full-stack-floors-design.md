# Full Stack, Floor by Floor

**Date:** 2026-11-06

**Supersedes:** the visual direction and the "no redesign", "no bright palette", "no inertial scrolling" and "no runtime libraries" non-goals of `2026-09-12-kinetic-portfolio-experience-design.md`, at the owner's request.

## Direction

The owner asked to base the site on the motion language of https://therechabite.com.au/. Mechanics are borrowed; assets are not. Its illustrations, crest, logo, licensed fonts and copy are not used.

Concept: scrolling descends the stack, from interface (Finly) to server (MAI Tablets) to metal (CubeSat), ending in a trophy room. The mascot is the owner's namesake, Alexander the Great, hence the helmet and personal crest.

## Motion inventory

Values were read from the reference's code rather than estimated.

| Effect | Implementation |
| --- | --- |
| Hero letters | Rise 40%, 0.8s `expo.out`, 15ms stagger with stickers in the same run |
| Cut letters | Base font outline minus curved shapes by even-odd fill. One per line, chosen once per render, never on a diagonal letter or under a sticker |
| Stickers | Rotation only: -3, 0 or 3 degrees in hard 0.3s steps. Floor title letters do the same in three staggered groups |
| Menu panel | Height over 0.5s `expo.inOut` (`cubic-bezier(.87,0,.13,1)`) |
| Menu rows | Rise 24px and fade, 0.5s `expo.out`, 30ms stagger, starting at 0.3s. Rows flip 90 degrees onto a colour face on hover. Bars: 0.3s `back.inOut`, 45 degrees, `scaleX(.8)` |
| Accordions | One open at a time; items rise 16px, 0.5s, 60ms stagger after 0.12s |
| Reel | 125lvh tall with a fixed `ellipse(100% 100% at 50% 100%)` clip; scenes cut on a timer |
| Floors | One sticky stage, one scroll step per floor. On each change the background tweens for 0.75s, the outgoing pieces blink off over 0.3s, the incoming pieces blink on from 0.21s, and the image travels `viewport + image` height. Images tilt up to 12 degrees toward the pointer |
| Quote | Letters from 20% to full opacity, random order, scrubbed by scroll |
| Footer word | Letters appear in random order over 0.8s and reverse when scrolling away |
| Flip buttons | 3D cube, 80 degree turn, -4 degree tilt, 300ms |

## Type

Display: Anton, with Oswald 700 for Cyrillic. Labels and buttons: Days One. Wordmark and footer: Forum. Body: Inter Tight with tight tracking. Each role was chosen by rendering candidates beside the reference.

## Illustration

`scripts/build-stickers.cjs` inks every contour as a filled, variable-width brush shape, and interior lines as tapered filled strokes. The subjects come from the owner's own story. They are generated by code, so they can be redrawn or replaced by commissioned art at any time.

## Constraints that still hold

- Content is complete without JavaScript or if `motion.js` fails.
- Reduced motion gets final states and nothing animating, including no smooth scrolling.
- No third-party requests. Fonts are self-hosted because a stalled font CDN blocks first paint.
- No horizontal overflow from 360px up.
